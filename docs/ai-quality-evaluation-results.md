- 구성원별 정답이 없는 추가 입력은 그룹 전체 정답으로 채점하지 않았다. 총 호출 19회와 채점 대상 수를 분리했다.
- 예약 식사가 끝나는 시각을 시작 시각으로 잘못 기재한 `overlapping-bookings`의 v1 정답은 품질 점수에서 제외했다(1개 사례). 원문 corpus와 모델 응답은 바꾸지 않았다.

- 도보 답변을 주석한 7개 입력은 보완 전 6개, 보완 후 7개가 정답과 일치했다. “20분까지 걷는 것은 괜찮지만 40분도 가능”에서 하나를 고르던 결과를 기존 재질문 상태로 바꿨다. 같은 응답을 보고 회귀 수정한 **개발 세트** 결과이며 새로운 입력에서의 개선율은 미검증이다.
- 최초 채점의 구성원/필드 집계 오류를 수정하고 저장한 원응답을 재채점했다. 채식 literal 누락과 빈 장소 문자열 판정도 채점기 버그로 수정했다. gold를 모델 결과에 맞춰 고치지 않았으며 사후 방법 수정은 JSON에 기록했다.

## 충돌 사례의 실제 처리와 한계

- 서로 반대인 지원 태그의 필수 음식/회피: 코드 회귀 검사에서 차단을 확인했다. 실제 모델의 그룹 예제는 `자연 식단` 의미와 중요도를 충분히 보존하지 못해 **미지원 제약 차단**으로 분류됐으며, 필수 충돌 탐지 성공으로 세지 않았다.
- 일반 선호 대 필수 회피: 구성원별 실제 응답에 제한된 태그 판정을 적용해 절충 대상으로 구분했다.
- 동일 시각의 다른 장소 예약·명시적 예약 구간 중복·겹치는 숙박: SQLite/합성 입력 회귀 검사에서 기존 본인 보완 DTO와 생성 차단을 확인했다. 잘못 주석한 v1 예약 사례의 실모델 성공률은 제시하지 않는다.
- 한 사람의 필수 포함/제외 의도와 일반 `likes`의 필수 중요도를 모두 표현하는 계약은 부족하다. 임의로 해결됐다고 표시하지 않았다. 예약 누락·중요도 보존·미지원 접근성/음식/반려견 조건은 후속 개선이 필요하다.
